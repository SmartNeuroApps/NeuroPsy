# NeuroPsy
Application and code to assess the relation between EEG data and success and failure in N-Back and AX-CPT games

The application is used to collect data for book chapter 
L ben Othmane, M Jedh, N Ahmed "Predicting Selective Attention and Cognitive Load From Brainwaves" in
book: Advanced Deep Learning Techniques for fNIRS and EEG Signal Classification, Springer, 2026
